# Cucina Fresca — Authentic Italian Joint, Mysuru

Crafting authentic Italian recipes, 72-hour fermented stone-baked pizza, and fresh handmade egg pasta in Saraswathipuram, Mysuru.

## Features
- 🍝 **Digital Menu & Ordering System**: Clean responsive interface for browsing salads, handmade pasta, lasagna, ravioli, stone-baked pizza, and Italian desserts.
- 📱 **QR Table Ordering**: Contactless table service ordering (`/table/07/`) with real-time floor assistance buttons (Call Waiter, Request Water, Request Bill, Clean Table).
- 🎨 **Modern Design System**: Built with Tailwind CSS utilities, custom espresso & gold accent color palette, Playfair Display & Plus Jakarta Sans typography, and vector Lucide icons.
- ⚡ **Zero-Dependency Node Server**: Built-in HTTP server (`server.js`) running on port `3000` (`npm run dev`).

## Quick Start
```bash
# Clone the repository
git clone https://github.com/chethud/-Cucina-Fresca.git

# Navigate to project directory
cd -Cucina-Fresca

# Launch local dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
